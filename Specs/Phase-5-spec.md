# phase-5-spec.md

## Phase 5 Name
图片搜索 + 设置完善 + 产品收尾优化

## Goal
完成图片按工地名称模糊搜索和日期筛选，补齐下载、预览、交互细节，并对全 App 做一次适老化和稳定性收尾。

## In Scope
1. 图片搜索页面
2. 按工地名称模糊搜索
3. 按日期或日期区间筛选
4. 搜索结果缩略图展示
5. 搜索结果单图下载
6. 设置页补充
7. 全局空态、错误态、文案、确认弹窗优化
8. 适老化优化

## Out of Scope
1. 云端备份
2. 多设备同步
3. 登录
4. 智能识图分类

## User Stories
1. 作为用户，我想按工地名快速找出以前拍的照片。
2. 作为用户，我想根据日期范围缩小搜索结果。
3. 作为用户，我想在搜索结果中直接下载某张照片到相册。
4. 作为视力较差的用户，我希望整个 App 都足够大、足够清楚。

## Functional Spec

### 1. 图片搜索页面
筛选条件：
- 工地名称关键字：支持模糊搜索
- 日期起始：选填
- 日期结束：选填

结果展示：
- 按图片批次或平铺缩略图展示，二选一
- MVP 建议：直接平铺所有命中图片，同时标注所属工地和日期
- 支持点击进入预览
- 支持下载

### 2. 搜索匹配规则
- 工地名称基于上传时保存的 siteNameSnapshot 做模糊匹配
- 日期基于批次 workDate 筛选
- 可支持单独用关键字搜索，也可组合日期范围

### 3. 搜索结果展示
每张结果至少展示：
- 缩略图
- 工地名称
- 日期

要求：
- 网格布局美观
- 条数变化时动态调整
- 空结果时明确提示“没有找到符合条件的图片”

### 4. 下载能力
- 搜索结果中的单张图片支持下载到系统相册
- 下载成功后有弹窗提示
- 支持打开系统相册或文件

### 5. 设置页完善
增加：
- 字体大小说明
- 关于应用
- 存储说明（例如“数据仅保存在本机”）
- 可选：清理临时缩略图缓存入口，如果实现了临时缩略图机制

### 6. 全局优化
需要统一检查并完善：
- 空页面文案
- 错误提示
- 权限拒绝提示
- 删除确认弹窗
- 导出成功提示
- 下载成功提示
- 首页按钮说明文字
- 长文本截断与换行策略

## Acceptance Criteria
1. 可按工地名称关键字模糊搜索图片。
2. 可按日期范围搜索图片。
3. 搜索结果可预览、可下载。
4. 空结果状态友好可理解。
5. 全 App 核心页面已完成适老化检查。
6. 设置页内容完整，文案清晰。

## QA Checklist
1. 输入部分工地名能否命中对应图片。
2. 仅选日期范围不输关键字能否搜索。
3. 日期范围非法时是否拦截。
4. 搜索结果很多时滚动是否流畅。
5. 搜索结果下载是否成功进入相册。
6. 字体超大模式下页面是否仍可用。
7. 首页、列表、表单是否都适合中老年用户阅读。
