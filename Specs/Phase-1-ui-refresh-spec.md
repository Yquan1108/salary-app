# phase-1-ui-refresh-spec.md

## Goal
在不改变 Phase 1 功能范围的前提下，重做视觉风格，使首页和引导页更现代、更清新、更像当下流行的工具类 App。

## Core Problem
当前版本虽然功能可用，但存在以下问题：
1. 配色老旧
2. 页面像传统管理系统
3. 引导页缺少品牌感和现代感
4. 首页卡片缺少层次
5. 整体不够“清爽、好看、愿意长期使用”

## Visual Direction
整体视觉方向：
- 清新
- 轻盈
- 现代
- 简洁
- 温和
- 高级但不冷淡

## Color System
建议采用以下配色方向，不要求一模一样，但风格必须接近：

### 主品牌色
- Fresh Green / Teal
- 例如：#22C55E / #14B8A6 / #10B981 这一类清新绿色或青绿色

### 背景色
- 暖白 / 浅灰白 / 浅青白
- 例如：#F8FAFC / #F9FAFB / #F5F7F8

### 卡片色
- 白色或略带暖调白色
- 保持轻阴影和大圆角

### 强调色
- 柔和橙色 / 金色
- 用于金额、重要提醒、统计结果
- 例如：#F59E0B 一类，但要降低廉价感

### 文本层级
- 主文字：深灰，不要纯黑
- 次文字：中灰
- 弱提示：浅灰

## UI Rules

### 1. Onboarding 重做要求
每页结构建议：
- 上半部分：主视觉图形区域
- 中间：主标题
- 下方：副标题
- 底部：分页指示器 + 下一步 / 进入按钮

每页内容：
1. 记工更轻松
   - 每天记一下，年底不用重新算
2. 工地照片好查找
   - 按日期和工地整理，老板要图时一找就有
3. 工资统计更省心
   - 按员工和时间筛选，一键导出工资表

设计要求：
- 背景可以加入浅色渐变或大色块装饰
- 主视觉用几何图形 + 图标表达，不要复杂插画
- 分页指示器更圆润
- 按钮更有品牌感
- 不允许出现“老式教程页”感觉

### 2. Home 重做要求
首页应包含：
- 顶部欢迎区域
- 4 个主功能卡片
- 2 个档案管理入口
- 设置入口

布局要求：
- 顶部可以加入一句亲和文案，例如：
  - 今天也轻松记工
  - 记工、存图、统计，都在这里
- 4 个主功能卡片做成两列布局
- 卡片采用不同浅色系点缀区分功能
- 卡片有图标、标题、说明
- 卡片圆角大、阴影轻、留白足

### 3. 卡片风格
- 圆角：20dp 左右
- 阴影：轻，不要厚重
- 内边距：足够大
- 局部可用浅色背景块增强层次
- 不要使用重描边方框

### 4. 按钮风格
- 主按钮使用品牌主色
- 次按钮使用浅底色 + 深色文字
- 删除类按钮使用柔和红，不要刺眼
- 按钮圆角明显，不要硬方形

### 5. 字体层级
- 页面主标题：明显更大更粗
- 功能标题：中等偏大
- 说明文字：简洁，避免大段文字
- 金额、条数等数字要突出

## Non-Goals
以下本轮不做：
1. 不改变已有功能逻辑
2. 不新增联网能力
3. 不增加复杂动画
4. 不为了炫技加入难维护特效

## Acceptance Criteria
1. 首页视觉明显比当前更现代
2. 引导页不再像老式说明页
3. 整体颜色清新，不灰、不脏、不土
4. 大字体模式下仍然好看
5. 功能不受影响，只做 UI 升级

## Codex Task Prompt
请基于现有 Phase 1 功能，对 UI 做一次视觉升级，但不要改动业务逻辑。

重点修改：
1. 重做 App 主题配色，改为清新、现代、耐看的风格
2. 重做 onboarding 页面，使其更像现代工具类 App
3. 重做 home 页面卡片样式、顶部区域、按钮样式
4. 优化全局圆角、阴影、背景层级、文字层级
5. 继续保持适老化：大字体、清晰、易点击

约束：
- 不修改 Phase 1 功能边界
- 不增加复杂动画
- 所有文案仍为中文
- 优先输出：
  - 主题色方案
  - Typography / Shape / Card / Button 样式调整
  - OnboardingScreen 重构
  - HomeScreen 重构

本次输出必须包含：
- 修改文件列表
- 新的配色与主题说明
- 引导页改动说明
- 首页改动说明
- 已知限制
